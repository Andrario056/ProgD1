Registrar certificado médico

Registra el examen, los tipos de exámenes realizados y la documentación del usuario. El certificado solo se procesa cuando el usuario cumple las vacunas obligatorias y el sello y la firma digital son válidos.

1. Datos del usuario y del examen

Busca un usuario registrado en la Sub-región Capital o regístralo si aún no existe.

¿El usuario no está registrado? Regístralo aquí

Completa los datos básicos para agregarlo a la sub-región y seleccionarlo automáticamente para el certificado.

2. Tipos de exámenes realizados

Agrega uno o varios exámenes. Todos los campos son obligatorios.

0 exámenes

Puedes agregar varios exámenes antes de procesar el certificado.

3. Documentación

Adjunta archivos PDF o fotografías, verifica el sello y la firma digital del documento.

4. Requisitos del usuario

    El certificado no se puede procesar dos veces ni sin cumplir todos los requisitos.
